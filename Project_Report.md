# Short Project Report
## College Event Management Website

### 1. Project Title
College Event Management Website

### 2. Objective
The objective of this project is to develop a responsive and user-friendly website for managing and presenting college events using HTML5, CSS3 and JavaScript.

### 3. Technologies Used
- HTML5 – page structure and semantic sections
- CSS3 – responsive design, cards, gallery effects and dark/light theme
- JavaScript – form validation, event filtering, digital clock and event selection

### 4. Main Modules
1. Home – college/department name, logo, navigation and introduction.
2. Events – five upcoming events with date, venue and description.
3. Registration – student registration form with JavaScript validation.
4. Gallery – six event images with hover effects.
5. About Us – department and coordinator details.
6. Contact – address,femail, phone and feedback form.

### 5. JavaScript Features
- Registration form validation
- Dark/light mode using localStorage
- Digital clock
- Dynamic event category filtering
- Event-specific registration button

### 6. Responsive Design
CSS media queries are used to support desktop, tablet and mobile screen sizes. The navigation changes to a mobile menu on smaller screens and the content grids automatically adjust.

### 7. How to Run
Open `index.html` in Google Chrome, Microsoft Edge, Firefox or another modern web browser. Internet access is required for the six remote gallery images. For offline submission, download six suitable images into an `images` folder and replace the image URLs in `index.html`.

### 9. Conclusion
The project demonstrates the use of HTML5, CSS3 and JavaScript to create a complete responsive college event management website with interactive client-side features.
